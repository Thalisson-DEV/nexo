Em caso de dúvida

  1. Abra um chamado — caminho recomendado

    No menu do sistema, acesse Chamados › Novo chamado. A dúvida fica registrada, recebe um responsável e a resposta pode ser acompanhada pelo próprio sistema. Use este caminho para solução formal ou ajuste de dados.

  2. Assistente Copiloto — dica rápida

    Para uma orientação imediata durante o preenchimento, abra o Copiloto pelo item "Copiloto" do menu lateral: uma tela própria de IA, disponível para quem tem acesso ao assistente.
